# Лабораторная работа 2. Решающие деревья и ансамбли

## Задание 1. Решающее дерево

1. Реализовать алгоритм построения решающего дерева классификации:
   - выбрать и обосновать критерий разбиения;
   - определить критерий остановки разбиения вершины на поддеревья;
   - реализовать стандартный интерфейс класса:
     - `fit`;
     - `predict`.

2. Обучить дерево на датасете [Mushroom](https://archive.ics.uci.edu/dataset/73/mushroom).

3. Оценить качество классификации на тестовой выборке и объяснить выбор используемых метрик качества.

> **Важно:** в датасете присутствует признак с пропущенными значениями. Модель должна корректно обрабатывать пропуски и продолжать работу.

### Задание со звёздочкой

Реализовать расчёт **важности признаков (feature importance)** для одного решающего дерева.

---

## Задание 2. Случайный лес

1. На основе реализованного решающего дерева построить случайный лес:
   - для каждого дерева случайным образом выбирать объекты и признаки для обучения 
   - реализовать механизм голосования деревьев;
   - добавить метод `predict_proba`.

2. Провести обучение и тестирование случайного леса.

3. Сравнить качество классификации случайного леса с одиночным решающим деревом.

4. Построить график зависимости точности классификации от количества деревьев в ансамбле.

5. Визуализировать уверенность модели в ответах с помощью `predict_proba`, отдельно рассмотрев неверно классифицированные объекты.

### Дополнительное исследование

Построить случайный лес из **решающих пней (decision stumps)** и сравнить его с лесом из глубоких решающих деревьев.

## Задание 4. AdaBoost

Реализовать алгоритм AdaBoost и провести его исследование:

1. Реализовать алгоритм.
2. Обучить модель и оценить качество классификации.
3. Сравнить результаты с другими реализованными моделями.
4. Построить график зависимости точности от количества деревьев в ансамбле.
5. Объяснить полученную зависимость.

---

## Задание 5. Сравнение с библиотечными реализациями

Использовать `scikit-learn` для обучения следующих моделей:

- `DecisionTreeClassifier`;
- `RandomForestClassifier`;
- `AdaBoostClassifier`.

Сравнить библиотечные реализации с собственными по качеству классификации и полученным результатам.
