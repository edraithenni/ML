# MLproj (JupyterLab)

## Scikit-learn project for breast cancer classification (benign/malignant) based on 30 numerical features

### Dataset source: [https://www.kaggle.com/datasets/erdemtaha/cancer-data/data](https://www.kaggle.com/datasets/erdemtaha/cancer-data/data)

The project includes several binary classification models demonstrating their accuracy, along with visualizations using Matplotlib.
