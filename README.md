# ML

Репозиторий с лабораторными и практическими заданиями по **Machine Learning**.

Каждая папка содержит отдельное задание, его реализацию и результаты экспериментов.

## Содержание

В репозитории рассматриваются основные методы машинного обучения:

- предобработка и анализ данных;
- визуализация данных;
- линейная регрессия;
- решающие деревья;
- случайный лес;
- ансамблевые методы;
- кластеризация;
- оценка и сравнение моделей.

В каждой директории находится отдельный `README.md` с описанием соответствующего задания.
