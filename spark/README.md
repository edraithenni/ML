## Задание 5. Spark MLlib

PySpark содержит библиотеку машинного обучения **MLlib**.

Для построения рекомендательной системы используется алгоритм **ALS (Alternating Least Squares)** — метод попеременных наименьших квадратов.

### Создание модели

```python
from pyspark.ml.recommendation import ALS

als = ALS(
    maxIter=5,                 # Количество итераций
    regParam=0.01,             # Параметр регуляризации
    userCol="userID",          # Столбец с ID пользователя
    itemCol="movieID",         # Столбец с ID фильма
    ratingCol="rating",        # Столбец с оценкой
    coldStartStrategy="drop"   # Исключение холодных пользователей/фильмов
)
```

### Обучение и оценка

1. Разделите данные на обучающую (80%) и тестовую (20%) выборки.
2. Обучите модель ALS на обучающей выборке.
3. Получите предсказания для тестовой выборки.
4. Оцените качество модели с помощью **RMSE (Root Mean Squared Error)** — корня из средней квадратичной ошибки.
