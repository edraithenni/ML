# Лабораторная работа 3. Свёрточные нейронные сети

## Цель работы

Изучить применение свёрточных нейронных сетей для обработки изображений на примере задачи регрессии ключевых точек лица.

В работе используется датасет **Facial Keypoints Detection**. Каждое изображение представляет собой чёрно-белое изображение лица размером `96 × 96`, для которого заданы координаты ключевых точек лица.

Модель должна предсказывать 15 ключевых точек, каждая из которых задаётся двумя координатами:

```text
(x1, y1), (x2, y2), ..., (x15, y15)
```

Таким образом, выход модели содержит 30 значений.

Исходные изображения в датасете достаточно однотипны: лица в основном расположены по центру и имеют небольшие различия в положении. Для повышения устойчивости модели необходимо использовать аугментации и обучить её корректно определять ключевые точки также на повёрнутых, смещённых и масштабированных изображениях.

Для аугментаций используется библиотека `albumentations`.

## Пример аугментаций

Примерный pipeline аугментаций может включать:

- сдвиг изображения;
- масштабирование;
- поворот;
- изменение яркости и контраста;
- размытие;
- добавление шума;
- нормализацию.

```python
import albumentations as A
import cv2
import numpy as np
from albumentations.pytorch import ToTensorV2


def get_train_transforms():
    return A.Compose(
        [
            A.ShiftScaleRotate(
                shift_limit=0.1,
                scale_limit=0.1,
                rotate_limit=30,
                interpolation=cv2.INTER_LINEAR,
                border_mode=cv2.BORDER_REFLECT,
                p=0.8
            ),

            A.RandomBrightnessContrast(
                brightness_limit=0.2,
                contrast_limit=0.2,
                p=0.5
            ),

            A.GaussianBlur(
                blur_limit=(3, 5),
                p=0.2
            ),

            A.GaussNoise(
                var_limit=(10.0, 50.0),
                p=0.3
            ),

            A.Normalize(
                mean=[0.5],
                std=[0.5]
            ),

            ToTensorV2()
        ],
        keypoint_params=A.KeypointParams(
            format="xy",
            remove_invisible=False
        )
    )


def apply_augmentation(image, keypoints, transform):
    augmented = transform(
        image=image.astype(np.float32),
        keypoints=keypoints
    )

    return (
        augmented["image"],
        np.array(augmented["keypoints"])
    )
```

Данный код является примером. Необходимо самостоятельно выбрать подходящие аугментации и понимать, как каждая из них влияет на изображение и координаты ключевых точек.

# Задание 0. Подготовка данных

Разделить обучающий датасет на:

- `train`;
- `validation`.

Тестовый набор не используется, поскольку в нём отсутствуют размеченные координаты ключевых точек.

В датасете присутствуют пропущенные значения. Возможны два варианта их обработки:

1. удалить все строки, содержащие пропущенные значения;
2. реализовать маскированную функцию потерь, которая учитывает только известные координаты.

Второй вариант является усложнённым.

Маскированный MSE:

\[
L =
\frac{
\sum_i m_i(\hat{y}_i-y_i)^2
}{
\sum_i m_i
},
\]

где:

- \(y_i\) — истинная координата;
- \(\hat{y}_i\) — предсказанная координата;
- \(m_i=1\), если координата известна;
- \(m_i=0\), если значение отсутствует.

# Задание 3. Архитектура нейронной сети

Реализовать свёрточную нейронную сеть для регрессии координат ключевых точек.

Пример архитектуры:

```python
import torch.nn as nn
import torch.nn.functional as F


class FacialKeypointsModel(nn.Module):
    def __init__(self):
        super().__init__()

        self.conv1 = nn.Conv2d(
            1,
            32,
            kernel_size=3,
            padding=1
        )
        self.bn1 = nn.BatchNorm2d(32)

        self.conv2 = nn.Conv2d(
            32,
            64,
            kernel_size=3,
            padding=1
        )
        self.bn2 = nn.BatchNorm2d(64)

        self.conv3 = nn.Conv2d(
            64,
            128,
            kernel_size=3,
            padding=1
        )
        self.bn3 = nn.BatchNorm2d(128)

        self.pool = nn.MaxPool2d(2, 2)
        self.dropout = nn.Dropout(0.2)

        self.fc1 = nn.Linear(
            128 * 12 * 12,
            512
        )

        self.fc2 = nn.Linear(
            512,
            30
        )

    def forward(self, x):
        x = self.pool(
            F.relu(
                self.bn1(
                    self.conv1(x)
                )
            )
        )

        x = self.pool(
            F.relu(
                self.bn2(
                    self.conv2(x)
                )
            )
        )

        x = self.pool(
            F.relu(
                self.bn3(
                    self.conv3(x)
                )
            )
        )

        x = x.view(x.size(0), -1)

        x = self.dropout(
            F.relu(
                self.fc1(x)
            )
        )

        x = self.fc2(x)

        return x
```

Размер входного изображения:

```text
1 × 96 × 96
```

После трёх операций `MaxPool2d(2, 2)` пространственный размер изменяется:

```text
96 × 96
→ 48 × 48
→ 24 × 24
→ 12 × 12
```

Последний слой содержит:

```text
30 выходов = 15 точек × 2 координаты
```
