# Лабораторная работа: Анализ цен на жильё в Бостоне

## Цель работы

Освоить методы предобработки и визуализации данных, построения и оценки линейной регрессии.

## Исходные данные

Используется датасет **Boston Housing**, содержащий **506 наблюдений**, **13 признаков** и целевую переменную **MEDV** — медианную стоимость жилья в тысячах долларов.

---

## Задание 1. Первичный анализ данных

- Проверить наличие пропущенных значений.
- Построить распределение `MEDV`:
  - гистограмму;
  - boxplot.
- Найти признаки с наибольшей корреляцией с `MEDV`.

## Задание 2. Предобработка данных

- Разбить данные на обучающую и тестовую выборки с помощью `train_test_split`:
  - `test_size=0.2`;
  - зафиксировать `random_state`.
- Нормализовать числовые признаки с помощью `StandardScaler`:
  - обучить scaler только на `train`;
  - применить его к `train` и `test`.
- Создать бинарный признак:

  ```text
  is_high_value = MEDV > 30
  ```

- Удалить выбросы по Z-score (`|Z| > 3`) только из обучающей выборки, чтобы не искажать оценку модели на тестовых данных.

## Задание 3. Визуализация данных

- Построить тепловую карту корреляций с помощью `seaborn.heatmap`.
- Построить scatter plot зависимости `RM` от `MEDV`:
  - `RM` — среднее количество комнат;
  - `MEDV` — медианная стоимость жилья.
- Построить график зависимости `MEDV` от `LSTAT` — доли населения с низким социально-экономическим статусом.

## Задание 4. Линейная регрессия

Построить модель линейной регрессии:

```text
MEDV ~ RM + LSTAT + PTRATIO
```

Модель обучается на `train` и оценивается на `test`.

Необходимо:

- Вывести коэффициенты модели и дать их интерпретацию.
- Оценить качество модели отдельно на `train` и `test`:
  - R²;
  - MAE;
  - RMSE.
- Сравнить метрики на обучающей и тестовой выборках и определить наличие переобучения.
- Рассчитать **VIF (Variance Inflation Factor)** для признаков модели и проверить наличие мультиколлинеарности.
- Построить график остатков `residuals vs predicted`.
- По графику остатков оценить выполнение предпосылок линейной регрессии:
  - гомоскедастичность;
  - отсутствие выраженных закономерностей в остатках.
